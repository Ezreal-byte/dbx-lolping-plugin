# lolPing Lite 0.2.2

**修复 Windows 在屏幕边缘触发后，轮盘在其他位置显示残缺或消失的问题。**

此前，在屏幕最左侧等边缘位置打开轮盘并留下信号后，再到屏幕中间打开轮盘，Windows 可能继续沿用旧的裁剪区域，导致新轮盘只显示一部分，甚至完全不显示。现在会在提交画面前同步变化后的窗口位置和大小，避免旧裁剪范围影响后续显示；隐藏后再次唤醒也会重新同步。

- **保持原有手感**：光标位置、轮盘中心、拖动阈值、方向判定和 C++ 输入监听均不变，不会把光标移到屏幕内侧。
- **避免额外开销**：只在覆盖窗口的位置或大小变化时同步，不对每一帧重复设置窗口几何信息。
- **兼容原有数据**：设置、自定义素材、离线扩展表情包继续使用，无需清空数据。
- **同步商店文案**：在桌面及其他软件窗口上打 LOL 信号和表情，基于 darrenprx/lolPing 改造。

光标仍受系统桌面边界限制，位于边缘的轮盘也可能超出屏幕；本次修复的是这种状态影响后续正常位置的显示。

## 下载与更新

- **Windows x64**：`io.dbx.lolping.lite-0.2.2-windows-x64.dbxp`
- **macOS Apple Silicon**：`io.dbx.lolping.lite-0.2.2-darwin-arm64.dbxp`
- **可选扩展表情包**：`lolping-extra-emotes-1.zip`，在插件设置中导入，无需解压；已导入的扩展包可继续使用。

先停止插件，再通过 DBX 的开发包安装入口导入对应平台的 `.dbxp`，然后重新启动。这些是供商店审核的未签名开发包；正式商店包由 dbx-store 审核签名。macOS 程序采用 ad-hoc 签名，未公证。

## 验证

Windows 本地通过 25 项 Rust 测试、17 个实际桌面显示场景和 17 项功能检查，覆盖四条边、四个角、随后在屏幕中间打开轮盘，以及隐藏后唤醒。实际桌面像素检查可在撤掉修复时复现缺失，恢复修复后通过；用户也已确认测试包正常。

Windows x64 / macOS arm64 CI 覆盖 TypeScript、C++、Rust 测试、release 构建、包结构与校验和、协议和资源流程。发布包使用对应提交的 CI 产物，大小与 SHA-256 记录在 `release-candidates.json` 和平台 `.artifact.json` 中。macOS 使用另一套窗口提交路径，本次未做 macOS 实机验收，CI 不替代辅助功能、全屏空间与输入手感验证。
