# lolPing Lite 0.2.1

本版将桌面覆盖层改为 Rust 原生绘制，移除覆盖层 WebView 及其浏览器子进程。设置页继续嵌入 DBX，原有配置、自定义素材和离线扩展包保持兼容。

## 主要优化

- **降低内存占用**：按当前画面范围分配渲染缓冲，空闲时释放；表情改为后台流式解码，限制同时保留的帧数。Windows 单屏本地采样：启动 39.3 MiB、表情 46.9–47.5 MiB、带音效信号 51.4 MiB、使用后空闲 47.0 MiB。统计为插件后端与子进程工作集，不含 DBX 宿主、设置页和单独计入的 GPU 内存；不是所有场景的峰值保证。
- **保持打信号手感**：沿用原 C++ 输入监听和手势判定；音效解码与设备初始化移到后台，复用光圈与图片缓存。外观设置修改不会重置正在进行的手势。
- **修复透明覆盖层**：关闭 Windows 系统边框、圆角与阴影，解决轮盘和信号周围出现灰色方框的问题。
- **轮盘字体更清晰**：PING / EMOTE / BACK 使用 Inter 字形，调整字重、间距和对齐；字形在输入开始前准备并缓存。
- **暂停状态更明确**：保留手动暂停、快捷键暂停，以及录制按键结束后恢复原暂停状态的行为。
- **扩展表情包更容易找到**：在“导入扩展表情包”后新增“去 GitHub 下载”按钮，打开本仓库 Release 页面，并提示 ZIP 文件名。
- **更新插件图标**：使用黄色问号信号标记。

保留信号/表情轮盘、点击信号、动画、音效、自定义图片/声音导入及全部现有设置；不包含房间或网络同步。

## 下载与更新

- **Windows x64**：`io.dbx.lolping.lite-0.2.1-windows-x64.dbxp`
- **macOS Apple Silicon**：`io.dbx.lolping.lite-0.2.1-darwin-arm64.dbxp`
- **可选扩展表情包**：`lolping-extra-emotes-1.zip`，新增 35 个表情；在插件设置中导入，无需解压。已有扩展包可继续使用。

更新前先停止插件，通过 DBX 的开发包安装入口导入对应平台的 `.dbxp`，然后重新启动。此处为未经过 DBX 商店签名的开发包；商店版本由 dbx-store 维护者审核签名。macOS 原生程序采用 ad-hoc 签名，未公证；辅助功能授权、全屏空间和多屏缩放仍需实机验证。

Windows 本地验证包含 103 项前端测试、24 项 Rust 测试、444 项 C++ 输入断言和 17 项桌面检查；跨平台 CI 检查测试、发布构建、包结构/校验和与协议/资源流程。CI 不能替代 macOS 实机权限和输入手感验收。
